# ANRE Grad I Trainer

Android wrapper for the tested ANRE Grad I Trainer web application.

The app packages the offline HTML trainer inside an Android WebView and preserves its localStorage data.

## Included
- 414 questions
- Learning mode
- Mistakes mode
- Quick test
- Exam simulation
- Statistics
- Offline operation
- LocalStorage persistence

The question/answer content is based on the supplied trainer file and is not presented as an official ANRE answer key.

The Android APK is built automatically with GitHub Actions.
